# 🇮🇳 Indian Suicide Analysis Dashboard | Tableau

An interactive Tableau data visualization project focused on analyzing suicide trends in India across different years, states, demographics, causes, and socioeconomic factors.

The project contains two analytical dashboards covering historical and recent suicide trends using structured datasets and Tableau visualizations.

---

## 📌 Project Overview

This project analyzes suicide-related data in India using Tableau dashboards.

The analysis focuses on identifying patterns across:

- Years
- States
- Gender
- Causes
- Education levels
- Income levels
- Marital status
- Methods used

The project is divided into two dashboards:

1. **Historical Trends & Demographic Insights**
2. **Recent Trends & Comparative Analysis**

---

## 🎯 Project Objectives

The main objectives of this project were:

- Analyze suicide trends across different years
- Compare suicide cases across Indian states
- Analyze gender-based patterns
- Analyze major causes associated with suicide cases
- Study socioeconomic factors
- Analyze education-level patterns
- Compare historical and recent trends
- Build interactive Tableau dashboards
- Present complex datasets through clear visualizations
- Extract meaningful patterns from the available data

---

## 🔎 Key Insights

Based on the dashboard analysis:

- Suicide cases show changes across the analyzed years.
- Male suicide cases are higher than female cases in the historical dataset.
- Some states account for a larger share of the recorded cases.
- Family-related and financial factors appear among the reported causes in the dataset.
- Hanging is recorded as a commonly reported method in the available data.

> These observations describe patterns present in the analyzed datasets and should not be interpreted as causal conclusions.

## ⚠️ Data Interpretation Note

This project is intended for **data analysis and visualization purposes**.

The visualizations represent patterns found in the datasets used for this project. They should not be interpreted as proof that any demographic, socioeconomic, or personal factor directly causes suicide.

Suicide is a complex issue involving multiple interacting factors, and statistical association does not establish causation.

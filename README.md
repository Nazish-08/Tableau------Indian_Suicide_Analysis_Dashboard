# 🇮🇳 Indian Suicide Analysis Dashboard (Tableau)

## 📊 Project Overview

This project analyzes suicide trends in India using interactive **Tableau dashboards**. The goal is to visualize patterns across different years, states, gender, causes, and socioeconomic factors to better understand the trends and key reasons behind suicide cases.

The project includes two dashboards:

* 📈 **Historical Trends & Demographic Insights (2001–2012)**
* 📊 **Recent Trends & Comparative Analysis (2019–2023)**

---

## 📂 Dataset Information

The dataset contains suicide statistics in India categorized by:

* 📅 Year
* 📍 State
* 👨‍🦱 Gender
* ⚠️ Causes of suicide
* 🎓 Education level
* 💰 Income level
* 💍 Marital status
* 🪢 Method used

These attributes help in analyzing demographic and social patterns.

## 📊 Dashboard 1: Historical Trends (2001–2012)

**Key Metrics**

* 📌 Total Suicide Cases: **13 Million**
* 👨 Male Suicides: **8 Million**
* 👩 Female Suicides: **5 Million**
* 🗓 Years Covered: **12 Years**

**Visualizations**

* 🗺 State-wise suicide distribution map
* 📈 Year-wise trend line
* 👨‍👩‍👧 Gender comparison chart
* 🎛 Interactive year filter

This dashboard highlights long-term suicide patterns and demographic differences.

---

## 📊 Dashboard 2: Recent Trends (2019–2023)

**Key Metrics**

* 📌 Total Cases: **2 Million**
* 🗓 Years Covered: **3 Years**
* 📉 Peak Year Change: **-4.48%**

**Visualizations**

* 📈 Year-wise comparison
* ⚠️ Cause-based analysis
* 💰 Socioeconomic category insights
* 🎓 Education level distribution
* 🎛 Interactive year slicer


## 🛠 Tools & Technologies

* 📊 **Tableau** – Data visualization and dashboards
* 📁 **CSV Dataset** – Data source

---

## 🔍 Key Insights

* 📈 Suicide cases show gradual growth across multiple years.
* 👨 Male suicide cases are significantly higher than female cases.
* 📍 Some states contribute a larger share of cases.
* ⚠️ Family issues and financial stress are major contributing factors.
* 🪢 Hanging is the most commonly used suicide method.
